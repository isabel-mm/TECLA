Term Extraction and Corpus Linguistics Application

TECLA

Una herramienta de código abierto para trabajar con la terminología de un dominio a partir de sus textos, sin necesidad de programar.

Probar en Google Colab Código en GitHub

El trabajo terminográfico, paso a paso

TECLA reúne en un mismo entorno las fases del trabajo terminográfico basado en corpus. Se recorren en orden, se puede volver atrás, y en cada momento quedan a la vista los parámetros y las cifras que intervienen en cada decisión.

1

Preparar el corpus

Se elige la carpeta con los documentos, en PDF o en texto plano. TECLA los convierte a texto, los limpia y los analiza lingüísticamente, y muestra los datos descriptivos de cada documento y del corpus: tokens, tipos, TTR, hápax, densidad léxica y longitud de oración.

2

Extraer los candidatos a término

Primero, una etapa lingüística: se buscan las secuencias que siguen los patrones gramaticales habituales de los términos. Después, una estadística: TF-IDF, C-value y NC-value se combinan en un índice de terminologicidad que ordena la lista.

3

Comprobar si el corpus es suficiente

Antes de dar por bueno un inventario conviene preguntarse si el corpus recoge la terminología del dominio. TECLA aplica cuatro tests de adecuación terminológica: cobertura, saturación, dispersión y estabilidad.

4

Revisar y exportar

Ningún sistema automático sustituye el juicio del especialista. Cada candidato se aprueba, se rechaza o se deja pendiente, con notas y con todas sus cifras a la vista. El inventario revisado se exporta a CSV y a TBX-Basic (ISO 30042).

Instalación

TECLA es un paquete de Python (versión 3.9 o superior) y funciona en un ordenador personal, sin equipos especiales.

git clone https://github.com/isabel-mm/TECLA.git
cd TECLA
pip install -e .

# Modelos lingüísticos para español e inglés
python -m spacy download es_core_news_md
python -m spacy download en_core_web_lg

# Abrir la interfaz gráfica
python gui/tecla_gui.py

También puede usarse desde la línea de comandos, con las órdenes tecla extract, tecla stats y tecla evaluate, o importarse desde un programa en Python.

Por qué una aplicación de escritorio

TECLA se instala y se ejecuta en el propio ordenador, y no como una aplicación web, por cuatro razones. El cuaderno de Google Colab es solo una muestra para probar la extracción.

Tus textos no salen de tu ordenador

Se trabaja a menudo con artículos y libros sujetos a derechos de autor, que no deben subirse a un servidor ajeno.

Reproducible

El código de cada versión queda publicado: cualquiera puede repetir un análisis con la misma herramienta.

Independiente

No hay un servidor que mantener ni un servicio del que depender.

Adaptable

La gramática de patrones es un fichero legible que puede modificarse o sustituirse por otra.
