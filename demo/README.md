# TECLA · demostración en línea

Demostración de [TECLA](https://github.com/isabel-mm/TECLA) (*Term Extraction and Corpus
Linguistics Application*): extrae candidatos a término de unos pocos textos con el mismo
procedimiento que la aplicación de escritorio.

Los textos que se suben se procesan en este servidor. Para trabajar con un corpus propio,
instala TECLA en tu ordenador.
