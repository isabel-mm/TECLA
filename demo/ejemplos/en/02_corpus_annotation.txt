Corpus annotation adds interpretative linguistic information to the texts of a corpus. The most common type of corpus annotation is part-of-speech tagging, in which each token receives a tag that indicates its word class. The tagset is the inventory of tags used by a tagger, and the annotation scheme describes how each tag must be applied. Lemmatisation groups the inflected word forms of a word under a single lemma, so that the frequency of the lemma can be counted.

Syntactic annotation, or parsing, assigns a syntactic structure to each sentence, and a corpus with syntactic annotation is called a treebank. Semantic annotation labels word senses or semantic fields. Named entity recognition identifies the names of people, organisations and places, and coreference annotation links the expressions that refer to the same entity.

Manual annotation requires annotation guidelines, which describe each category of the annotation scheme and the criteria for difficult cases. When two annotators label the same texts, inter-annotator agreement measures how consistently the annotation guidelines can be applied. A low inter-annotator agreement usually means that the annotation scheme is ambiguous. Automatic annotation is faster than manual annotation, but its error rate must be estimated against a manually annotated sample, which is called a gold standard.

An annotation tool stores the labels either as inline annotation, inside the text, or as stand-off annotation, in a separate file that points to positions in the text. Stand-off annotation makes it possible to add several annotation layers to the same corpus without modifying the original texts.
