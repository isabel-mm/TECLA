Registro de tiempos
===================

Cada vez que se ejecuta el pipeline, TECLA anota cuánto tarda cada etapa
(conversión de los documentos, análisis lingüístico, extracción) en el fichero
``tecla_debug.txt``, dentro de la carpeta de resultados del corpus
(``_tecla_output/``, junto a los gráficos). Las sesiones se acumulan en el mismo
fichero. Sirve para diagnosticar un proceso lento; para el uso normal de la
herramienta puede ignorarse.
